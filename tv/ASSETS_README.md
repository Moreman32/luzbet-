# LuzBet TV — графический комплект

Комплект использует фотографию Стаса как эталон внешности. Ведущий и студии разделены: `assets/host/` и `assets/reactions/` содержат прозрачные передние слои, `assets/studios/` — самостоятельные фоны без людей. Реквизит, который ведущий держит или использует непосредственно, может входить в передний слой. У некоторых реакций вместе с ведущим сохранена нижняя поверхность стола.

План комплекта: 137 изображений WebP 1920×1080 — 24 образа по четыре кадра (96), 12 реакций, 14 студий, 15 заставок. Фактическая полнота, размеры, объём, SHA-256 и относительные пути записаны в `assets-manifest.json`; поле `complete` является проверяемым признаком завершённости. Контроль анимации находится в `quality-report.json`.

## Просмотр

Откройте `preview.html` в браузере. Он работает локально без внешних сервисов: манифест встроен в HTML, изображения загружаются из соседней папки `assets/`. Можно независимо менять образ, фон, кадр мимики, включать речь и моргание, проверять прозрачность на шахматной подложке и просматривать заставки с программно наложенными названиями.

`assets/previews/contact-sheet.jpg` показывает все базовые образы, реакции, студии и заставки. В `assets/previews/animations/` находятся уменьшенные анимационные WebP для проверки каждой серии. Эти превью не входят в число 137 рабочих изображений.

## Подключение к движку

При создании ресурсов в исходной локальной копии не было папки `tv/` или телевизионного движка. Перед загрузкой получена актуальная ветка `feature/luzbet-tv` (базовый коммит `14a05337c86d8594bceb7074864e3265938734be`). В этой ветке уже есть `tv/index.html` и пустой `host.json`. Движок и корневой `index.html` сохранены без изменений; `host.json` заполнен совместимыми полями `idle`/`talk` и дополнительными `talkWide`/`blink`.

`host.json` содержит 24 ключа поз. В каждой позе используются поля `idle`, `talk`, `talkWide`, `blink`. Все пути считаются от папки `tv/`.

Используйте общий холст 1920×1080 и обычное наложение `source-over`: сначала студия, затем передний слой ведущего. Размер, положение и обрезка должны быть одинаковыми для всех четырёх кадров одной позы. Нельзя обрезать каждый кадр по его непрозрачным границам или независимо подгонять лицо под размер блока.

```css
.tv-stage { position: relative; aspect-ratio: 16 / 9; overflow: hidden; }
.tv-stage > img { position: absolute; inset: 0; width: 100%; height: 100%; }
```

Перед анимацией загрузите все четыре кадра. Переключайте видимость уже загруженных изображений. `blink` рассчитан на краткое моргание около 100–140 мс; речевые кадры переключаются по данным озвучки или с небольшим переменным интервалом. Эталон поведения есть в `preview.html`. Автоматическое переключение в просмотрщике — демонстрация, не синхронизация фонем с аудио.

У `weather` ведущий смещён влево для работы с экраном; остальные образы преимущественно центральные. Фоны имеют разную архитектуру и высоту нижней поверхности. При подборе сцен проверяйте стык рук/реквизита со столом. Для свободного комбинирования сцен этот стык можно прикрывать отдельной нижней телевизионной плашкой.

Заставки в `assets/intros/` не содержат встроенных названий передач. Манифест задаёт `overlayTitle` и нормализованную `titleSafeArea`; текст можно локализовать и рисовать HTML, Canvas или средствами движка. Бренд «Лузбет» на микрофоне, газете, чашках и декорациях является частью соответствующих изображений.

## Как изготовлены кадры

Изображения и редактирования созданы встроенным `image_gen`; внешние платные API и CLI генерации не подключались. Сначала создавался `idle`, затем из него — варианты рта и глаз. Первоначальные цельные сцены использованы как фотографические исходники, а не как рабочие фоны ведущего.

При генеративном удалении фона менялась текстура кожи. Поэтому итоговая обработка сохраняет RGB исходного фотографического кадра и использует из результата удаления фона только альфа-маску. Отдельно удаляется отсоединённый мусор маски. В шести образах границы человека дополнительно уточнены локальной сегментацией Apple Vision; выбранные маски сохранены в `tools/masks/`. Для кошки сохраняются оба основных компонента. Маска одинакова внутри серии.

Из результатов редактирования мимики берутся только области рта или глаз, с мягким краем внутри области правки. Остальные видимые пиксели берутся из одного `idle`. Области определены локально Apple Vision по чертам лица и сохранены в `source-catalog.json`. Экспорт передних слоёв — WebP без потерь; фоны и заставки — WebP с качеством 92. Изображения приведены к 1920×1080 методом Lanczos.

## Проверки и повторная сборка

Нужны Python 3 (стандартная библиотека), Node.js, FFmpeg и FFprobe. Python не требует Pillow или других устанавливаемых пакетов.

```sh
python3 tv/tools/verify.py --complete
python3 tv/tools/previews.py --animations
```

Проверка требует существования всех 137 ресурсов, формата и размера 1920×1080, альфа-канала передних слоёв, 24 полных наборов `host.json`, различия кадров мимики, совпадения масок и точного совпадения видимых пикселей вне областей рта/глаз во всех 72 сравнениях. RGB полностью прозрачных пикселей не сравнивается: WebP может оптимизировать невидимые значения.

Для повторной обработки исходников на этом компьютере:

```sh
python3 tv/tools/layered.py
python3 tv/tools/reactions.py
python3 tv/tools/assets.py --ingest tv/other-sources.json
python3 tv/tools/verify.py --complete
python3 tv/tools/previews.py --animations
```

`source-catalog.json`, `reaction-catalog.json`, `other-sources.json` и `asset-spec.json` содержат происхождение ресурсов, сцены и промты. Пути к генеративным PNG в каталогах являются локальными архивными путями Codex и не нужны для использования готовых WebP. При переносе сборки исходников на другой компьютер эти PNG следует перенести отдельно и обновить пути. Исходная личная фотография не копируется в публикуемый графический комплект.

Автоматические проверки подтверждают техническую согласованность. Узнаваемость, детали рук, краёв волос и правдоподобие реквизита дополнительно проверяются визуально; это генеративные изображения, а не покадровая видеозапись человека. Контактный лист и просмотрщик позволяют оценить каждый образ перед включением в эфир.
